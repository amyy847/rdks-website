# Brief: "Our land portfolio" section for the RD.K website

## Goal
The client wants the site to show that RD.K owns several plots of land, not just one project. The point is credibility: visitors should see a developer with a portfolio and a pipeline. Autovia stays the headline project. The other plots are presented as upcoming commercial developments.

## The plots
| Plot | Arabic name | Area | Status |
|---|---|---|---|
| Autovia | أرض ١٣٠٠٠ | 13,000 m² | Current launch (already on the site) |
| Plot 9000 | أرض ٩٠٠٠ | 9,000 m² | Upcoming |
| Engineers Syndicate plot | أرض نقابة المهندسين | Not public | Upcoming |
| Sadat plot | أرض السادات | Not public | Upcoming |

All of them are for **commercial use**: shops, retail, showrooms and similar.

## Key rule: keep details private
Don't show prices, layouts, exact locations or specs. All details are given only after a visitor sends an enquiry. Each plot card should therefore show very little and push people to the existing **Enquire now** form.

## What to build
1. **Homepage section**, placed directly under "Current launches" (Autovia).
   - Title idea: "Our land portfolio" or "Future developments".
   - One short intro line, for example: "Beyond Autovia, RD.K holds a growing portfolio of commercial land for retail, showrooms and business destinations."
   - Optional stat row to sell the scale: number of plots (4) and total known area (22,000+ m²). Add the other areas only if the client provides them.
2. **One card per upcoming plot** (3 cards):
   - Plot name, with the Arabic name as a small subtitle if it fits the design.
   - Use tag: "Commercial · Retail & showrooms".
   - Status badge: "Upcoming".
   - Area only where we have it (9,000 m²). Otherwise leave it out, don't write "TBC".
   - CTA button: "Enquire for details". It opens or scrolls to the Enquire now form with that plot pre-selected.
3. **Enquire now form**: add the three plots to the "Interest" dropdown (in the main form and the footer form), so the sales team knows which plot each lead is about.
4. **Developments page**: add "Current" and "Upcoming" tabs, or an "Upcoming" group under Autovia, using the same cards.

## Look and feel
- Match the existing site: dark, moody, warm earth tones, elegant and understated.
- No renders exist, so don't use fake building images. Use one of these instead:
  - Blueprint-style line art of a plot outline on a fine grid
  - Abstract contour or topographic lines in the brand's warm accent colour
  - A darkened, warm-toned aerial or satellite-style photo with a dashed site boundary
- Keep the cards consistent: same image ratio, a badge in the same corner, CTA in the same place.
- The inspiration images are attached separately. The mockup is here: https://claude.ai/artifact/1EEySNXhHAABokywfNZR9c (it shows more detail per card than we now want; follow this brief where they differ).

## Copy tone
Confident and short, like the rest of the site. Suggested lines:
- Section: "More destinations in the making."
- Card CTA: "Enquire for details"
- Under the cards: "Details on each plot are shared on request. Send us an enquiry and our team will be in touch."
